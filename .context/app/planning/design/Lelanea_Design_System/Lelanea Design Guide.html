Lelanea Design System

A coaching app where clients sit with an AI trained on Lelanea's Unity Consciousness work.

design guide · colour · type · motion · components

This guide documents the visual and verbal patterns of Lelanea's App. The product should feel like a warm room, not a dashboard — contemplative, grounded, and quiet. Every rule below exists to protect that feeling.

the one thing to remember

Warm earthy neutrals hold the space; meditative teals carry the brand; burnt orange is ceremonial and used almost nowhere. When in doubt, remove something and add space.

Colour

The palette pairs warm, earthy neutrals with meditative blues. Backgrounds are never pure white or pure black — oyster white in light mode, near-black charcoal in dark. The burnt orange is the ceremonial accent: it marks the lotus core and the single primary action on a screen, and appears nowhere else.

Light and dark mode

Both modes are first-class. Dark mode is not an inversion — the warm neutrals stay warm, and body text shifts to warm soft stone rather than white. Borders flip from 24% dark ash to 12% warm stone. Cards gain a hairline border in dark mode only, to separate them from the near-black background.

Typography

Three faces, each with one job. Instrument Serif carries every heading and hero line — it is what makes the product feel literary rather than clinical. Hanken Grotesk handles all body and UI text. Cormorant Garamond italic appears only for pull quotes and reflection prompts, where it reads as Lelanea's own voice.

No font files were supplied for this brand. All three faces are Google Fonts chosen to carry the intended mood. If Lelanea has a real type specification, swap it in and re-tune the scale; the token names will not need to change.

Space, shape and elevation

Spacing

An 8-point scale, used from the generous end. Phone gutters are 24px minimum; 16px is reserved for tight inline groupings like an icon beside a label. Card padding is 20–24px.

Radii

Nothing in the product has a hard corner except full-bleed sections, which have no corners at all. Pills are used for every button and floating control.

Elevation

Two layers only. --shadow-rest for resting cards; --shadow-lift for modals and the active lotus halo. Inner shadows are never used. The single coloured shadow in the system is the orange bloom behind the lotus core and the primary CTA.

Motion

The product breathes; it does not perform. There are no bounces, no springs, and no overshoot anywhere in the system. Fades are preferred to slides, and where translation is used it is 4–8px at most.

--ease-breathcubic-bezier(0.22, 0.61, 0.36, 1)Everything expressive

Interaction states

  • Hover — background deepens roughly 6%; never shifts hue and never brightens. Text links gain a 1px underline at 3px offset with no colour change.
  • Press — scale(0.98) over 120ms on the breath easing. Background flattens one step; no colour shift.
  • Focus — 1px deep-teal border plus a 3px teal glow at 15% opacity.
  • Disabled — 45% opacity, no colour change.

The lotus

The lotus is the only illustration in the system and the only decorative mark. It opens once when the app launches, then settles into an ambient breath — a 4s cycle scaling between 1.0 and 1.015. Navigating away and back does not retrigger the opening.

Its geometry is three tiers of broad pointed petals radiating from a single base point, drawn so the bloom is slightly wider than tall (measured 134 × 118, aspect 1.14). All three tiers fan out broadly, which is what keeps it reading as a full flower rather than a tall spike.

Three concentric sage ripples sit beneath the bloom, fading outward. They read as stillness on water and expand into place as the flower opens. Earlier drafts used lily pads; those were dropped as too heavy and too literal for a contemplative setting.

sizing

On both Lotus and LotusMark, the size prop is the rendered width of the bloom, not of the SVG frame — so the two are interchangeable at the same size. Pass water={false} for marks under about 40px; it crops the frame tight to the petals so the flower stays legible at avatar scale.

Layout conventions

  • Single column on mobile; content caps at 560px on wider surfaces.
  • Fixed elements are limited to the status bar, the chat composer, and the tab bar. Everything else scrolls.
  • Backdrop blur appears on exactly two surfaces: the status bar over scrolling content, and the chat capsule. There are no frosted-glass cards.
  • Floating controls sit in solid capsules, not gradient scrims. The one exception is a 64px protection gradient above the chat composer.
  • Tap targets are never smaller than 44px.

Voice

Copy should read like a soft voice in a quiet room. It speaks to the client as "you", asks more than it tells, and never performs mysticism. The AI does not refer to itself as an AI; it says "let's sit with that", not "I think".

Do

  • Sentence case everywhere, including buttons.
  • Questions over answers.
  • Em dashes for breath; ellipses sparingly.
  • Words like presence, witness, arrive, return.
  • Lowercase tracked-out eyebrows: a place to return to.

Don't

  • No exclamation points. None, ever.
  • No emoji. The lotus is the only ornament.
  • No Title Case on buttons or labels.
  • No stacked mystical vocabulary.
  • Never "the user" — always "you".

Iconography

Icons should feel like small drawings, not wayfinding glyphs. The system uses Lucide as its baseline family — 1.5px stroke, rounded caps, open geometry. Icons are never filled and never bicolour. They inherit text colour, sitting at silver-ash when at rest and deep teal when active. Sizes are 16, 20 and 24, with 24 the default.

The lotus mark is the only custom glyph, used as the app icon, the AI's avatar in chat, and a small mark above pull quotes. Emoji are never used. The one permitted unicode ornament is a thin bullet in meta text — 4 min · yesterday.

substitution — please review

Lucide was chosen as the closest available match to the intended tone. If Lelanea has a custom icon set, it should replace Lucide wholesale rather than being mixed with it.

Sharing this system

The system is a folder of plain files, so it travels as-is. There are three routes, depending on what the other project needs.

1. Attach it as a design system

Any other project in this workspace can bind this project directly as its design system. It then gets the tokens, the seven components, and every preview card without copying anything. This is the best option for ongoing design work.

2. Hand over the folder as a skill

Download the whole project as a zip. It contains a SKILL.md written to the Agent Skills format, so dropping the folder into another Claude project — or into a .claude/skills/ directory for Claude Code — makes it invocable as lelanea-design. That agent reads README.md and works from the same rules as this guide.

3. Send this document

For a human collaborator — a developer, a contractor, a founder — export this guide to PDF and send it. It carries every value needed to build correctly without any tooling.
